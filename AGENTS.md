# Vendor Onboarding AI — Agent Instructions

## Project Purpose
This project assists with checking vendor
registration document completeness.

## Development Guidelines
- Follow existing project conventions.
- Use Python 3.11 or newer.
- Write readable and maintainable code.
- Add tests for new validation logic.

## Security Rules
- Never hardcode passwords or API keys.
- Use synthetic data during demonstrations.
- Do not modify production records.

## Verification
- Run the relevant tests after changes.
- Report failed tests.
- Do not claim success without verification.

## Human Approval
Request approval before deployment
or changes affecting live vendor records.
